# بسته‌ی انتشار ذهن‌ساز (کافه‌بازار / مایکت)

همه‌ی چیزهایی که برای صفحه‌ی برنامه در فروشگاه لازم است، در همین پوشه است.

## ۱. مشخصات برنامه

| مورد | مقدار |
|---|---|
| نام برنامه (نمایشی) | **ذهن‌ساز** (انگلیسی: Zehnsaz) |
| نام بسته (applicationId) | **`com.barati.zehnsaz`** |
| نسخه | versionName `1.0` · versionCode `1` |
| حداقل اندروید | 7.0 (API 24) · هدف: API 35 |
| دسته‌بندی پیشنهادی | آموزشی (یا: سلامت و تندرستی) |
| رده‌ی سنی پیشنهادی | همه‌ی سنین (+۳) |

> **مهم درباره‌ی نام بسته:** روی شاخه‌ی `main` هنوز `com.example.zehnchin` است. تغییر به
> `com.barati.zehnsaz` در PR #22 آماده است و باید **قبل از اولین آپلود** ادغام شود، چون
> کافه‌بازار نام بسته‌ی `com.example.*` را نمی‌پذیرد و بعد از انتشار هم دیگر قابل تغییر نیست.

## ۲. آیکون

- `icon-512.png` — آیکون ۵۱۲×۵۱۲ برای صفحه‌ی فروشگاه.
- `icon.svg` — فایل منبع (برای ویرایش‌های بعدی).
- آیکون داخل برنامه هم با همین طرح عوض شده است (لایه‌های adaptive در `res/drawable` و
  نسخه‌های webp در `res/mipmap-*` برای اندروید ۷ تا ۷.۱، به‌علاوه‌ی لایه‌ی تک‌رنگ برای
  آیکون‌های رنگی‌شده‌ی اندروید ۱۳).

طرح: مغزی سفید با دو نیم‌کره و یک «نقطه‌ی تمرکز» کهربایی در مرکز، روی زمینه‌ی بنفش به
صورتی تمشکی (همان رنگ‌های اصلی برنامه). پیام آن: توجه و تمرکز.

## ۳. توضیح کوتاه (حداکثر ۸۰ نویسه)

```
تمرین‌های علمی توجه، تمرکز و حافظه با ارزیابی دوره‌ای و نمودار پیشرفت
```

## ۴. توضیح کامل

```
ذهن‌ساز؛ باشگاه ورزشی ذهن شما 🧠

ذهن‌ساز مجموعه‌ای از تمرین‌های کوتاه و بازی‌گونه است که بر پایه‌ی آزمون‌های شناخته‌شده‌ی علوم اعصاب شناختی طراحی شده‌اند تا توجه، تمرکز و دیگر توانایی‌های ذهنی‌تان را به چالش بکشند. روزی چند دقیقه تمرین کنید، امتیاز بگیرید و پیشرفتتان را روی نمودار ببینید.

🎯 شش حوزه‌ی شناختی
• توجه و تمرکز: پیدا کردن هدف در میان محرک‌های مشابه (جست‌وجوی دیداری)
• حافظه‌ی فعال: به خاطر سپردن و بازگو کردن توالی‌ها
• سرعت پردازش: تصمیم‌گیری سریع و دقیق
• کنترل تکانه: مهار پاسخ در تمرین «برو / نرو»
• انعطاف ذهنی: جابه‌جایی بین قاعده‌ها
• حل مسئله و برنامه‌ریزی: پازل‌های مرتب‌سازی که باید از پیش برایشان نقشه کشید

📊 ارزیابی پایه، جدا از تمرین
هر ۱۴ روز سه آزمون کوتاه و استاندارد انجام دهید: توجه پایدار (gradCPT)، شبکه‌های توجه (ANT) و حافظه‌ی کاری (2-back). نتیجه‌ها با شاخص‌های علمی مثل حساسیت (d′)، خطای ارتکاب و حذف، و اثر تعارض گزارش می‌شوند تا پیشرفت واقعی، نه فقط مهارت در بازی، دیده شود.

📅 برنامه‌ی هفتگی هوشمند
برنامه‌ی هر هفته از حوزه‌هایی شروع می‌شود که دقت شما در آن‌ها کمتر است.

⚡ سختی تطبیقی
سرعت و دشواری تمرین‌ها با عملکرد شما تنظیم می‌شود تا نه خسته‌کننده باشد و نه ناامیدکننده.

🏆 انگیزه برای ادامه
سکه، ستاره، دستاورد، جایزه‌ی روزانه و روزهای متوالی تمرین. یادآور روزانه‌ی اختیاری هم دارد.

🌈 طراحی شاد و خوانا
رنگ‌های روشن و پرانرژی، فونت فارسی وزیرمتن، و رنگ‌بندی حوزه‌ها که برای افراد دارای کوررنگی هم قابل تشخیص است.

🔒 بدون نیاز به ثبت‌نام
همه‌ی داده‌های شما روی گوشی خودتان ذخیره می‌شود.

⚠️ ذهن‌ساز ابزار تشخیص یا درمان پزشکی نیست و جایگزین ارزیابی متخصص نمی‌شود. اگر نگران وضعیت توجه، حافظه یا تمرکز خود هستید، با پزشک یا روان‌شناس مشورت کنید.
```

## ۶. تصاویر صفحه (اسکرین‌شات)

پنج تصویر ۱۰۸۰×۱۹۲۰ در پوشه‌ی `screenshots/`:

1. `1-home.png` — صفحه‌ی خانه
2. `2-chapters.png` — فصل‌های آموزشی
3. `3-attention.png` — تمرین توجه انتخابی
4. `4-profile.png` — پروفایل، برنامه‌ی هفتگی و روند ارزیابی
5. `5-assessment.png` — ارزیابی پایه

> این تصاویر **ماکت** هستند: از روی کد صفحه‌ها و رنگ‌های جدید برنامه (PR #23) ساخته شده‌اند،
> چون در محیط ابری امکان اجرای اندروید نبود. عددهای داخلشان نمونه‌اند. منبع آن‌ها
> `mockup/screens.html` است و با `node docs/store/mockup/render-screens.js` دوباره ساخته
> می‌شوند. بهتر است پیش از انتشار با تصاویر واقعی جایگزین شوند (پایین را ببینید).

### گرفتن اسکرین‌شات واقعی در Android Studio

1. PRهای #22 و #23 را ادغام کنید و برنامه را روی شبیه‌ساز Pixel (اندروید ۱۳ یا بالاتر) اجرا کنید.
2. چند مرحله بازی کنید و یک ارزیابی پایه انجام دهید تا پروفایل و نمودارها داده داشته باشند.
3. در پنجره‌ی Running Devices دکمه‌ی دوربین (Take screenshot) را بزنید، یا در ترمینال:
   `adb exec-out screencap -p > 1-home.png`
4. همان پنج صفحه‌ی بالا را بگیرید و جایگزین فایل‌های `screenshots/` کنید.
